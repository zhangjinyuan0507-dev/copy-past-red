# 红外车辆拼贴工具（IR Vehicle Cut-Paste）

在红外航拍背景图上**点击摆放车辆**，并自动生成 **VOC XML / YOLO** 标注的浏览器工具。纯前端、无后端、不上传任何数据。

## 怎么用
1. 打开页面（用 **Chrome / Edge** 最佳）。
2. **加载背景图**：把整个文件夹**拖进窗口**，或点「打开文件夹」选文件夹（载入全部），或 Ctrl+A 全选。
3. **摆放车辆**：点空白处放一辆；点已有车=选中并拖动；拖框**四角**=等比缩放；拖动**上方圆点**=旋转。
4. **融合参数**：大小/亮暗/对比/模糊/旋转；调好的值会自动成为新车的默认值。
5. **删除**：选中后按 `Delete`/`Backspace`，或点右下角「框选结果」的 ✕。
6. **保存**：点「选择保存文件夹…」选一个根目录 → 「保存当前图片 / 保存全部标注」→ 自动生成
   - `images/`（**无框**合成图）
   - `xml/`（**VOC** 标注，与图同名）
7. 快捷键：`1-4` 车型、`z` 撤销、`c` 清空、`s` 保存当前、`←/→` 切图、滚轮缩放、拖空白或右键平移。

## 浏览器要求
- **Chrome / Edge** 优先：支持「保存到文件夹」（File System Access API）。
- Firefox / Safari：保存会自动退化为「下载」`png+xml`，其余功能可用。
- 需 **HTTPS**（静态托管均已提供）才能"保存到文件夹"。

## 部署（GitHub Pages）
- 直接推本仓库到 GitHub，在仓库 Settings → Pages 开启，即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。
