# 红外车辆拼贴工具 v2 · IR Vehicle Cut-Paste v2

在红外航拍背景图上点击摆放车辆，自动生成 **合成图 + VOC XML 标注**。纯前端、无后端、不上传任何数据。

> 本目录是 **v2 新版**，旧版仍在上一层目录（[`../`](../)）。两版可同时打开对照，产出格式相同。

顶部「模式」下拉切换，**两套互不相干**，各自用不同的输出目录：

| 模式 | 类别（官方 ID） | 素材 | 说明 |
| --- | --- | --- | --- |
| **基础四类** | 0 `car1` 装甲车 · 1 `car2` 卡车 · 2 `car3` 轿车 · 3 `car4` 皮卡 | 66 个（11 建模 × 6 视角，随页面加载） | 旧类别表，**ID 不变、顺序不变** |
| **类增量（新四类）** | 4 `radar_vehicle` 雷达车 · 5 `military_fuel_tanker` 军用油罐车 · 6 `bridge_layer` 轮式架桥车 · 7 `military_motorcycle` 军用越野摩托车 | 24 个（4 建模 × 6 视角，切到该模式时按需加载 1.5MB） | 新类**只能从 ID 4 起追加**，不改动旧四类 |

- 切模式会同时切换：可选素材、类别下拉、`1-4` 快捷键含义、统计面板、自动均衡的目标类别；**已摆放的车不会丢**（素材下标全局唯一），但会提示混用。
- 同一张图/同一批里混了两套数据时，「标注计划」下方会出现**黄色警告**（含数量），并提供「删除本图不属于当前模式的车」一键清理。保存状态里也会带模式标记与混用提示。
- 建议：基础四类与类增量各自选一个输出根目录，`images/` `xml/` 结构完全一致。

## 怎么用

1. 用 **Chrome / Edge** 打开本页，顶部选好**模式**。
2. **加载背景图**：把整个文件夹拖进窗口，或点「打开文件夹」选一个目录（载入全部）。
3. **摆放车辆**：点空白处放一辆；点已有车 = 选中并拖动；拖框**四角** = 等比缩放；拖动**上方圆点** = 旋转。
4. **指定类别**：按 `1`~`4`（对应当前模式四类），或用下拉框；不指定则按全图类别占比自动平衡（目标每类约 25%）。
5. **融合参数**：大小 / 亮暗 / 对比 / 模糊 / 旋转；大小与旋转的调整会成为下一辆的默认值。
6. **删除**：选中后按 `Delete` / `Backspace`，或点右下角「框选结果」的 ✕。
7. **保存**：点「选择保存文件夹…」选根目录 → 「保存当前图片 / 保存全部标注」→ 生成
   - `images/`（**无框**合成图，`<背景图名>_composite.png`）
   - `xml/`（**VOC** 标注，`<背景图名>.xml`）
8. 快捷键：`1-4` 类别、`z` 撤销、`c` 清空、`s` 保存当前、`←/→` 切图、滚轮缩放、拖空白或右键平移。

## 标注框口径

- XML `bndbox` 是**标准 VOC**：`(xmin, ymin)` 左上角、`(xmax, ymax)` 右下角，`<depth>1</depth>`（红外灰度）。类别名写在 `<name>`，取值即上表的 `class_name`；类别 ID 见上表（用于 YOLO 编号，本工具不写进 XML）。
- 框 = 车辆**实体**（素材 alpha 边界）在图像上的外接矩形，含旋转后的轴对齐外框；超出画布的部分会被裁掉。
- 素材预处理：按 alpha 裁剪 → 等比缩放到「实体最长边 = 画布 512 的 92%」→ 居中 → 转灰度+alpha。
  这样同一「大小」滑块在不同车型/视角上含义一致；灰度化不影响结果，因为融合阶段本来就会把像素统一按亮度重映射。
- 注意：实体归一化后，摩托车这类小目标在同一个滑块值下看起来会和卡车一样长——按实际需要调小「大小」即可（面板会显示实体像素尺寸）。

## 素材与来源

- 基础四类：`vehicle_review_pack_20261008_v1/01_透明样本`（11 建模 × 6 视角 = 66 张）。
- 类增量新四类：`vehicle_incremental_blend_review_20261008_v3/01_透明样本`（4 建模 × 6 视角 = 24 张，class_id 4~7，与包内 `建模规格.json` / `样本清单.csv` 一致）。
- 构建命令（会与包内清单逐张交叉校验，不一致直接报错）：

```bat
python scripts\build_cutpaste_sprites.py ^
  --base-pack "<vehicle_review_pack_20261008_v1 目录>" ^
  --incr-pack "<vehicle_incremental_blend_review_20261008_v3 目录>" ^
  --out "<本目录>"
```

- 两个包都标注为 **QA 候选**（`qa_only: true`、`approved: false`、`license_allows_training: false`）；增量包的参考来源是厂家公开外观资料，几何为程序化首版、隐藏尺寸为估算。**投入训练前须完成外观与使用权复核，并确定专用车与旧卡车的互斥标注边界。**
- 同一建模的所有视角共享 family，划分训练/验证/测试时不要把同一建模的不同视角拆开；新旧两套数据也应各自成集、不要混在一张图里。

## 浏览器要求

- **Chrome / Edge** 优先：支持「保存到文件夹」（File System Access API）。
- Firefox / Safari：保存会自动退化为「下载」`png + xml`，其余功能可用。
- 需 **HTTPS**（静态托管均已提供）才能「保存到文件夹」；直接双击本地文件打开时，部分浏览器会因画布安全限制无法导出图片（请用本机 HTTP 服务或线上地址打开）。
