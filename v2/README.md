# 红外车辆拼贴工具 v2 · IR Vehicle Cut-Paste v2

在红外航拍背景图上点击摆放车辆，自动生成 **合成图 + VOC XML 标注**。纯前端、无后端、不上传任何数据。

> 本目录是 **v2 新版**，旧版仍在上一层目录（[`../`](../)）。两版可以同时打开对照、产出可以混用（标注格式相同）。

## v2 相对旧版改了什么

| # | 变更 | 说明 |
| --- | --- | --- |
| 1 | **素材库换成 66 个透明渲染车** | 11 个车型 × 6 个视角（方位 0°/120°/240° × 离正俯视 30°/60°），来自 `vehicle_review_pack_20261008_v1/01_透明样本`；旧版只有 4 张素材（每类 1 张） |
| 2 | **类别表按官方口径** | `car1 装甲车 / car2 卡车 / car3 轿车 / car4 皮卡`。旧版下拉框把 **car2/car4 的中文名写反了**（旧版显示 car2 皮卡、car4 卡车），产出的 XML 里 `car2`/`car4` 与实际车型是错位的，v2 已修正 |
| 3 | **标注框改为「车辆实体范围」** | 按素材 alpha 透明边界计算，不再用整张素材画布。旧版框里大半是透明留白（例：卡车实体宽 415px，旧版框却是 1024px） |
| 4 | **自动挑选车型/视角** | 摆放时从该类别里随机取一个车型/视角（不会连续重复同一个）；面板显示「已放/建议」以及下一个将使用的素材；`1-4` 或下拉框可指定类别（下一辆生效，之后回自动） |

输出格式与旧版完全一致（`images/` 无框合成图 + `xml/` VOC 标注、同名），所以新旧两版的产出可以直接混在同一个数据集里。

## 怎么用

1. 用 **Chrome / Edge** 打开本页。
2. **加载背景图**：把整个文件夹拖进窗口，或点「打开文件夹」选一个目录（载入全部）。
3. **摆放车辆**：点空白处放一辆；点已有车 = 选中并拖动；拖框**四角** = 等比缩放；拖动**上方圆点** = 旋转。
4. **指定类别**：按 `1`~`4`，或用右上角下拉框；不指定时按全图类别占比自动平衡（目标每类约 25%）。
5. **融合参数**：大小 / 亮暗 / 对比 / 模糊 / 旋转；调好的值会自动成为新车的默认值。
6. **删除**：选中后按 `Delete` / `Backspace`，或点右下角「框选结果」的 ✕。
7. **保存**：点「选择保存文件夹…」选一个根目录 → 「保存当前图片 / 保存全部标注」→ 生成
   - `images/`（**无框**合成图，文件名 `<背景图名>_composite.png`）
   - `xml/`（**VOC** 标注，文件名 `<背景图名>.xml`）
8. 快捷键：`1-4` 类别、`z` 撤销、`c` 清空、`s` 保存当前、`←/→` 切图、滚轮缩放、拖空白或右键平移。

## 标注框口径

- XML 的 `bndbox` 是**标准 VOC**：`(xmin, ymin)` 左上角、`(xmax, ymax)` 右下角，`<depth>1</depth>`（红外灰度）。
- 框 = 车辆**实体**（素材 alpha 边界）在图像上的外接矩形，含旋转后的轴对齐外框；超出画布的部分会被裁掉。
- 素材预处理：按 alpha 边界裁剪 → 等比缩放到「实体最长边 = 画布 512 的 92%」→ 居中；并转成灰度+alpha。
  这样每个素材的实体都居中、大小一致，同一「大小」滑块在不同车型/视角上含义相同；灰度化不影响结果，因为贴图融合阶段本来就会把像素统一按亮度重映射。

## 素材与来源

- 素材来自透明渲染样本包（11 车型 × 6 视角，66 张），由
  `scripts/build_cutpaste_v2_assets.py` 预处理后内嵌进 `vehicles_v2.js`（构建统计见 `build_report.json`）。
- 样本包标注为 **QA 候选**（`qa_only: true`、`training_approved: false`），来源许可状态为
  `project_generated_output_terms_pending`；**正式训练前需完成外观与使用权复核**。
- 同一车型的所有视角共享 family，划分训练/验证/测试时不要把同一车型的不同视角拆开。

## 浏览器要求

- **Chrome / Edge** 优先：支持「保存到文件夹」（File System Access API）。
- Firefox / Safari：保存会自动退化为「下载」`png + xml`，其余功能可用。
- 需 **HTTPS**（静态托管均已提供）才能「保存到文件夹」；直接双击本地文件打开时，部分浏览器会因为画布安全限制无法导出图片（此时请用本机 HTTP 服务或线上地址打开）。
